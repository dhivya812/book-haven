# 📚 Book Haven – Online Book Store

## 🔹 Overview
Book Haven is a simple web-based online bookstore application that allows users to browse books and add them to a cart. This project demonstrates basic frontend development and client-side storage using JavaScript.

---

## 🚀 Features
- 📖 View list of available books  
- 🛒 Add books to cart  
- 💾 Cart data stored using browser Local Storage  
- 💰 Calculate total price dynamically  
- 🎨 Simple and responsive UI  

---

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript
